# ResumeAI 🚀

**ResumeAI** is an AI-powered resume evaluation web application that analyzes uploaded resumes and provides a score, strengths, weaknesses, and actionable recommendations to help users improve their chances of landing a job.


🔗 **Live Demo:** https://resume210.onrender.com/

---

## ✨ Features

- 📄 Upload resumes in **PDF format**
- 🤖 AI-powered resume analysis
- 📊 Resume scoring system
- ✅ Highlights **Strengths**
- ⚠️ Identifies **Improvements**
- 💡 Provides **Key Recommendations**
- 🎨 Clean, modern, responsive UI

## 🔌 How REST API Is Used

- The frontend sends the uploaded resume file to the backend using **HTTP POST requests**
- Backend processes the resume and sends it to the **LLM API**
- AI-generated feedback is returned as **JSON**
- Frontend consumes this data and displays:
  - Resume score
  - Strengths
  - Improvements
  - Recommendations

This project follows a **client–server REST API architecture**.
